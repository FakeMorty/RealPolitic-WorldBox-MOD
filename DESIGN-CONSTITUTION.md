# ДИЗАЙН: Конституция (Этап 26)

> Статус: обсуждение (до кода). Решено: набор статей — строгий политический;
> действия мода подчиняются жёстко; ванильные войны — «неконституционный акт»
> с наказанием через последствия. Этот документ — единый контур; меняется
> только по согласованию с игроком.

## 1. Что такое конституция в нашем мире

Конституция — приватный свод правил государства, **записанный** (в реленции
справедливой власти) и **исполняемый**: каждое решение мода, которому есть
соответствующая статья, сначала спрашивает у конституции «можно ли?».
Если нет — решение не происходит, точка. Правитель против закона = правитель
с падающей легитимностью и восстающими городами — механика Этапа 17 уже здесь.

Конституция живёт как часть `KingdomPolitics`: одна на государство, унаследованная
от отца-основателя при отделении/распаде, сбрасываемая революцией.

## 2. Статьи (строгий политический набор, 6 штук)

### 2.1. Форма правления — подвид внутри идеологии (ArticleHeadOfState)
Форма НЕ свободный параметр: она рождается из текущей идеологии державы — но у
многих идеологий есть **конституционные подвиды**, и вот в чём соль конституции.
Меняет подвид правитель-реформатор, собрание или сам народ (§3).

| Идеология | Возможные формы (подвиды) | Закон наследования (Этап 16 |
|---|---|---|
| Племя (Tribalism) | Вождь старшин (наследственно) · Совет старейшин | Tanistry / CouncilOfElders |
| Монархия | **Абсолютная** · Выборная · Парламентская | Primogeniture/Salic · Tanistry-выборная · ConstitutionalPrimogeniture |
| Деспотия (Despotism) | Единоличная тирания (подвидов нет) | StrongestHand |
| Милитаризм | Стратократия (военный совет) | Stratocracy |
| Теократия | Иерархия выборная (клир совет) | TheocraticElection |
| Аристократия | Сенат знати | CouncilOfLords |
| Торговая республика | Дружина (совет купцов) | GuildCouncil |
| Демократия | **Президентская** · Парламентская | DemocraticElection |
| Уравнительная община | Народное вече | PopularAssembly |
| Технократия | Совет директоров (подвидов нет) | BoardCouncil |
| Этнонационализм | Единый вождь нации (подвидов нет) | LeaderCult |
| Коммунизм | Советская держава (партиийный конгресс) | PartyCongress |
| Фашизм/Империализм | Единолично (подвидов нет) | LeaderCult |

**Три монархии — это три разные страны:**
- Абсолютная: трон без камер, война и границы — королевская воля.
- Выборная: король выбирается танистром (сословный корпус: лидеры городов + династия).
- Парламентская: наследный король, но война — ТОЛЬКО с согласия палаты (см. 2.3).

Парламентская демократия = президент выборный, но война с согласия сената;
президентская — исполнительная ветвь решает сама.

### 2.2. Избирательный закон (ArticleFranchise)
Активно только когда 2.1 = Elected или Council.
- `Universal` — все взрослые граждане столицы и городов: голоса считаются по
  именам настоящих юнитов (у нас есть поошелёная идеология — Этап 8).
- `Notables` — голосуют лидеры городов + ближайшая родня правящей династии.
- `Clan` — только члены правящего клана (племена и родовые монархии).

### 2.3. Объявление войны — наследует форму правления (ArticleWarDeclaration)
По исторической логике: сильная центральная власть решает войну единолично,
народная — собранием.

| Форма | Война решает |
|---|---|
| Абсолютная монархия, деспотия, стратократия, этнонационализм (вождь нации), фашизм, коммунитстая советская держава (центральный аппарат), техносбыт совет директоров, торговая дружина | `ByRuler` — правитель лично |
| Парламентская монархия, парламентская демократия, аристократический сенат, совет старейшин, выборная монархия (курфюрсты), теократический клир | `ByAssembly` — голосование палаты: лидеры городов + знать/клир (см. §5) |
| Президентская демократия | `ByRuler` — исполнительная ветвь решает сама. Исторически так: великие войны XX века не выносились на всенародный плебисцит |
| Народное вече (уравнительная община) | `ByPeople` — голосуют все взрослые жители державы |

Самостоятельно менять эту статью правитель не может — только вместе со сменой
формы правления в 2.1 (которую оформляет §3). Это и есть «конституционная стойка»:
нельзя остаться демократом и при этом просто украсть себе право на войну.

### 2.4. Границы (ArticleBorderLaw)
- `Open` — границы не закрываются никогда (`ApplyBorderPolicy` отключён для этого
  государства, даже в войну).
- `Controlled` — как сейчас: ИИ-политика, автоматическое закрытие, облава (Этап 23).
- `Closed` — всегда закрыты, выдворение ножками по вашему правилам.

### 2.5. Престолонаследие по конституции (ArticleSuccessionRule)
Дополняет 2.1: если статья = Hereditary, то конституционно фиксируется строгий
закон (переходящий в атрибут порядка наследования из Этапа 16: права первородства,
салический, танистро…), и **любой сменой правителя вне этого закона считается
переворотом** (легитимность ×0.6, хроника «акт узурпации»).
Значения: `StrictSuccession` / `AnyAdult` — по существу: законно ли править
тому, кого игра поставила на трон сама, когда он вне линии.

### 2.6. Верховенство конституции (ArticleSupremacy)
- `Binding` — конституция выше правителя: все гейты из §4 действуют в редакции
  «запретить». Нарушение правителем самой конституции → импичмент-каскад (§6).
- `Advisory` — обычай: гейты не запрещают, а только ударяют по легитимности
  (кто хоть ж даже правит хорошо, не очень интересуется законом).

## 3. Откуда конституция берётся и как меняется

**Начальная редакция** — по умолчанию под виду идеологии:
точнее, из таблицы 2.1 форма правления выбирается ДЕФОЛТНЫМ подвидом
(монархия по умолчанию абсолютная; демократия президентская; племя — вождь старшин),
а 2.3 выводится из неё. Эпоха ограничивает разнообразие: парламентская монархия
появляется только с Нового времени — механика эпох 0.20.x уже умеет это.

**Правки правителем** (раз в RulerConstitutionalEditYears = 15 лет, только
при легитимности > 50): правитель меняет ОДНУ статью. Выбор правдела
— из характера (Этап 19) + угроз (Этап 18): tyrant ужесточает ByPeople → ByRuler;
народный любимец ослабляет границы. Каждая правка — событие в летопись:
«Правитель N изменил статью «объявление войны»: было ByAssembly, стало ByRuler.
Народ встречает холодом» (-4 легитимности за спешку смены, тщательно обсуждали по сроку).

**Правки народом**: при ArticleSupremacy=Binding и AvgDissent > 0.35 триггерится
«конституционный кризис» — референдум на одну из спорных статей (см. §5).
Так конституция дышит с обеих сторон.

**Революция/отделение**: новая держава наследует конституцию родителя и сразу
проводит «учредительное собрание» — 1–2 статьи меняются автоматически под
идеологию мятежа.

## 4. Матрица принуждения: где код спрашивает конституцию

| Действие мода (файл) | Статья | При отказе |
|---|---|---|
| Выборы (`ElectionSystem`) | 2.1 Elected; 2.2 — электорат | Нет выборов — не проводятся; наследование по закону |
| Наследование (`RefreshRulers`) | 2.5 StrictSuccession | Правитель вне линии = «актузурпации»: легит ×0.6, запись |
| Объявление войны (советник/стратегия) | 2.3 | Война для этого государства запрещена (см. §7) |
| Границы (`ApplyBorderPolicy`) | 2.4 | Open → никаких облав; Closed → всегда выдворение |
| Рейды/бомбёжка(`Bombardment*`) | 2.3 (война = её продолжение) | Рейд невозможен без разрешения как войны |
| Пленум/собрание | 2.1 Council | Без council — собрания по существу нет |
| Регентство (0.20.x) | 2.5 | Норма регентства ≤18 лет остаётся общей для Hereditary |

Блокировка = **честная тишина**: стратегия просто не выбирает запрещённое действие;
нет корявых сообщений об ошибке. Хроника пишет САМО событие голосования и исход.

## 5. Голосования и референдумы (реальные, не бумажные)

**Электорат** берётся у самой игры:
- Universal: взрослые юниты городов державы (все найденные Actor.units);
- Notables: лидеры городов + совершеннолетняя родня правящего клана;
- Clan: взрослые члены правящего клана.
Лимит сканирования: до 200 голосующих на собрание (капитал-вес > периферии 2:1).

**Процедура** (раз в ReferendumCooldownYears = 10 лет на тему):
1. Событие: «Собрание державы N обсуждает: разрешить войну с X?»
2. Подсчёт: голос пришёл из весов Ideology-привязанностей ДА/НЕТ (по идеологии
   каждого голосующего + война-усталость + страх и лояльность). Порог: строгое
   большинство (>50%). Кворум: ≥ 5 голосов.
3. Исход в летопись с реальными числами: «ЗА 67, против 54. Война разрешена».
4. Результат фиксируется в `PendingWarAuthorization` на 1 год: объявление войны
   в этом направлении теперь конституционно. По истечении — сгорело.

Сенат для Council-формы: фиксированная палата из лидеров городов + глав кланов,
вечное присутствие; голосует также по Person + CountTab.

UI: референдум **виден игроку на время** (флажок на государстве в окне королевства
«идёт голосование: 4 дней»), потом запись. Голоса ЯВНО посчитаны, не сгенерированы.

## 6. Последствия нарушения (каскад)

- Война по ванильному триггеру (обход конституции) → «акт вне конституции»:
  легитимность -12, хроника, при повторе ≥2 — кризис: мятеж по причине
  «Нарушена конституция» (новая CivilWarCause).
- Узурпатор (§2.5) → легит ×0.6 + CivilWarcause «права на трон».
- Binding: правитель, закрывший войну без разрешения собрания → через год
  собрание выносит votum desiderii → его же замещение (выборы по 2.2).

## 7. Чего конституция НЕ умеет (договорено)

1. Не сдерживает голод, геноцид и значение игры. Если Игра сама объявила войну —
   мы это хроним как прецедент и караем правителя, но не ломаем игру попытками
   гасить чужие конфликты. (Выбор:mod_only со стороны пользователя).
2. Не двигает войска и не меняет мир на карте сама по себе — только через
   уже СУЩЕСТВУЮЩИЕ механики (границы, выборы, наследование, мятежи).
3. Не прячется за fakes: если выбор очередного решения нельзя до конца
   выполнить (например, «голосовал ли именно этот конкретный юнит») —
   статистика пишется честно как «выборка совета по именам».

## 8. Технический контур реализации

- Ядро: `Constitution.cs` (enum статей + класс Constitution с 6 полями-енумами),
  `ConstitutionDefaults.cs` (по идеологии/эпохе), `ConstitutionGates.cs` (чистые
  функции CanDeclareWar/CanHoldElections/GetElectorate). Тесты: ≥ 30, включая
  «Universal-голоса прощитаны из выборки имен» и «при ByRuler всё как раньше».
- Игра: точки из §4 (правки небольшие, чтение одного объекта),
  окно `ConstitutionWindow` — просмотр статей; режим редактора вкладывается в 26.2.
- Сериализация: SaveData v14 (6 int на государство — байт-совместимо, у старых
  сохранений поля отсутствуют → Defaults по текущей идеологии).
- Летопись: 3 рубрики отмечаются отдельными префиксами [КОНСТИТУЦИЯ],
  чтобы по префиксу сразу было видно её «руку».
